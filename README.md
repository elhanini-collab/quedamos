# Quedamos

PWA personal para no perder el contacto con amigos, conocidos y ex-compañeros.

- Cadencia por persona (cada cuánto quieres hablar o quedar)
- Propuesta semanal de 3 personas a las que escribir
- Registro en un toque: mensaje, llamada o quedada
- Cumpleaños, notas e historial
- Datos guardados en el navegador (localStorage), con exportar/importar en JSON

Vanilla JS, sin dependencias. Publicada con GitHub Pages.
